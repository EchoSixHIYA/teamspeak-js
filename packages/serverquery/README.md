# @honeybbq/teamspeak-serverquery

A TeamSpeak ServerQuery client: the administration interface a server offers
over raw TCP (10011), SSH (10022) and the HTTP WebQuery (10080).

**Not yet published.** This package is a skeleton: the typed commands from
`@honeybbq/teamspeak-core` already run on any `CommandExecutor`, and this is
where the ServerQuery one will live. It is implemented before 1.0.0.
